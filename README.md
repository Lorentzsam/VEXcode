# VEXcode

VEX V5 codes，based on [PROS](https://pros.cs.purdue.edu/) (kernel 4.2.2, C++)。

## environment

- PROS CLI 3.5.6（`pipx install pros-cli`）
- Arm GNU Toolchain（`arm-none-eabi-gcc`）

## Function

- brc.hpp : Defines the Robot class and creates motors for general use
- profile.hpp : Creates profile for different Robots
